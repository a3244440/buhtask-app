# Skill: Красивые лёгкие анимации для BuhTask

## Объясняю как ребёнку 🧒

Представь, что сайт — это дом. Анимации — это не праздничные гирлянды на каждом углу, а **мягкий свет, который включается, когда ты заходишь в комнату**. Немного, к месту, приятно. Если гирлянды повесить везде — глаза устанут, и дом станет медленным. Наше правило: **лучше меньше, но вкуснее**.

Три золотых правила:
1. **Анимация должна помогать**, а не развлекать. Появился блок — плавно «всплыл». Навёл на карточку — она чуть «приподнялась». Всё.
2. **Быстро и коротко**: 150–400 мс. Дольше — сайт кажется тормозным.
3. **Двигаем только `transform` и `opacity`**. Никогда не анимируем width/height/top/left — от этого сайт лагает.

## Что за проект (контекст)

- **BuhTask** — платформа для бухгалтеров и бизнеса Казахстана: маркетплейс бухгалтеров + бесплатные инструменты.
- Стек: **Next.js 16 (App Router) + Tailwind CSS**, всё в `app/`, переводы в `lib/i18n.tsx` (функция `t('ключ')`, три языка ru/kz/en — **любой новый текст добавляй во все три**).
- Главная страница (лендинг): `app/page.tsx`.
- Цвета бренда: синий `#2F80ED` (blue-600), зелёный emerald, фон `#F8FAFC`, жёлтый акцент `yellow-300`. Есть тёмная тема (переменная `D` в page.tsx).
- Иконки: **lucide-react** (уже установлен).
- ❗ Библиотеки анимаций (framer-motion и т.п.) **НЕ ставить** — всё делаем на CSS/Tailwind. Это легче и быстрее.

## Готовые кирпичики (копируй и используй)

### 1. Плавное появление при прокрутке (Reveal)
Один маленький компонент — блоки «всплывают», когда доезжаешь до них скроллом.

Создай `app/components/Reveal.tsx`:
```tsx
'use client';
import { useEffect, useRef, useState } from 'react';

export default function Reveal({ children, delay = 0, className = '' }:
  { children: React.ReactNode; delay?: number; className?: string }) {
  const ref = useRef<HTMLDivElement>(null);
  const [shown, setShown] = useState(false);
  useEffect(() => {
    const el = ref.current; if (!el) return;
    const io = new IntersectionObserver(([e]) => {
      if (e.isIntersecting) { setShown(true); io.disconnect(); }
    }, { threshold: 0.15 });
    io.observe(el);
    return () => io.disconnect();
  }, []);
  return (
    <div ref={ref} className={className} style={{
      opacity: shown ? 1 : 0,
      transform: shown ? 'none' : 'translateY(18px)',
      transition: `opacity .5s ease-out ${delay}ms, transform .5s ease-out ${delay}ms`,
    }}>{children}</div>
  );
}
```
Использование: оберни секцию `<Reveal>...</Reveal>`. Для сетки карточек давай ступенчатую задержку: `<Reveal delay={i * 60}>` — карточки появляются одна за другой, как домино. Задержку больше 400 мс не делать.

### 2. Карточка с «подъёмом» при наведении
Только Tailwind, без JS:
```
className="transition-all duration-200 ease-out hover:-translate-y-1 hover:shadow-lg hover:border-blue-200"
```
Иконка внутри может чуть увеличиваться: на карточке `group`, на иконке `transition-transform duration-200 group-hover:scale-110`.

### 3. Мягкий «живой» фон в hero (градиентные пятна)
Два размытых круга за текстом, очень медленно дышат:
```tsx
<div aria-hidden className="absolute inset-0 overflow-hidden pointer-events-none">
  <div className="absolute -top-24 -left-24 w-96 h-96 rounded-full bg-blue-400/20 blur-3xl animate-blob" />
  <div className="absolute -bottom-24 -right-24 w-96 h-96 rounded-full bg-emerald-400/20 blur-3xl animate-blob" style={{ animationDelay: '4s' }} />
</div>
```
Keyframes добавь в `app/globals.css`:
```css
@keyframes blob { 0%,100% { transform: translate(0,0) scale(1); } 50% { transform: translate(24px,-18px) scale(1.06); } }
.animate-blob { animation: blob 14s ease-in-out infinite; }
@media (prefers-reduced-motion: reduce) {
  .animate-blob, [style*="transition"] { animation: none !important; transition: none !important; }
}
```
`prefers-reduced-motion` обязателен — если человек в настройках телефона попросил меньше анимаций, мы уважаем это.

### 4. Кнопка со «стрелкой, которая уезжает»
```tsx
<button className="group ...">Открыть <ArrowRight className="w-4 h-4 transition-transform duration-200 group-hover:translate-x-1" /></button>
```

### 5. Счётчик, который «набегает» (для цифр типа «11 инструментов»)
Использовать редко, максимум один блок на страницу.

## Главная задача: секция «Все инструменты» на лендинге

В `app/page.tsx` после баннера «Доход 910» (ищи комментарий `Инструмент ФНО 910`) добавь секцию:

1. Заголовок: «Бесплатные инструменты» + подзаголовок «11 инструментов для бухгалтера и бизнеса — всё в одном месте» (ключи в i18n: `land.toolsTitle`, `land.toolsSub`, ru/kz/en).
2. Сетка: `grid sm:grid-cols-2 lg:grid-cols-3 gap-4` (на телефоне — одна колонка).
3. Карточка = ссылка на инструмент: иконка в цветном квадратике (`bg-{color}-50 text-{color}-600`, скруглённый `rounded-xl`), название жирным, описание серым мелким, стрелка справа.
4. Каждую карточку оберни в `<Reveal delay={i * 60}>` — эффект домино.
5. Карточкам — hover-подъём из кирпичика №2.
6. ❗ Tailwind не видит динамические классы `bg-${color}-50` — прописывай классы целиком в объекте данных (как строку `color: 'bg-pink-50 text-pink-600'`).
7. Уважай тёмную тему: у page.tsx есть флаг `D` — для карточек в тёмной теме фон `bg-gray-800`, текст светлый (посмотри, как сделаны соседние секции, и повтори их подход).

## Где ещё добавить «щепотку» анимаций (по чуть-чуть!)

- Hero: заголовок и кнопки — `<Reveal>` c задержками 0/100/200 мс + градиентные пятна (кирпичик 3).
- Категории услуг и карточки бухгалтеров: hover-подъём.
- Баннер «Доход 910»: кнопке — уезжающая стрелка (кирпичик 4).
- Шапка: у ссылок плавный underline — `after:` псевдоэлемент с `scale-x-0 → scale-x-100`.
- Больше НИЧЕГО. Не анимируй каждый элемент — это главный признак плохого вкуса.

## Чего делать НЕЛЬЗЯ 🚫

- Не ставить npm-пакеты анимаций (framer-motion, gsap, aos, lottie).
- Не анимировать width/height/top/left/margin — только transform и opacity.
- Не делать анимации дольше 500 мс и бесконечные мигания/вращения (кроме blur-пятен фона).
- Не трогать логику: API (`app/api/**`), расчёты инструментов, авторизацию, i18n-механику.
- Не удалять существующие секции лендинга — только добавлять/украшать.
- Не забывать три языка для каждого нового текста.

## Как проверить, что всё хорошо ✅

1. `npm run build` — обязан пройти без ошибок (перед этим `npm install --legacy-peer-deps`).
2. Открой глазами: анимации едва заметные? На телефоне (узкий экран) ничего не ломается? В тёмной теме читается?
3. Прокрути страницу быстро — ничего не дёргается, не прыгает?
4. Если сомневаешься «добавить ещё анимацию или нет» — НЕ добавляй. Сдержанность = дорогой вид.
