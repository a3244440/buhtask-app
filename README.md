# BuhTask - Маркетплейс бухгалтерских услуг

Платформа для онлайн-бухгалтерии и поиска бухгалтерских услуг в Казахстане.

## Описание проекта

BuhTask — это цифровая SaaS-платформа и marketplace бухгалтерских услуг, где предприниматели находят проверенных бухгалтеров, ставят задачи онлайн и получают доступные бухгалтерские услуги из любой точки Казахстана.

## Технологический стек

- **Frontend**: Next.js 16, React 19, TypeScript
- **Styling**: Tailwind CSS 4
- **Backend/Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth (Phone OTP)
- **State Management**: Zustand
- **Icons**: Lucide React

## Установка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка Supabase

1. Создайте проект на [supabase.com](https://supabase.com)
2. Выполните SQL из файла `database/schema.sql` в SQL Editor
3. Включите Phone Auth в Settings → Authentication → Providers

### 3. Настройка переменных окружения

Отредактируйте `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3000

### 5. Сборка для продакшена
```bash
npm run build
npm start
```

## База данных

### Основные таблицы:
- `profiles` - профили пользователей
- `clients` - профили заказчиков (ИП/ТОО)
- `accountants` - профили бухгалтеров
- `tasks` - задачи
- `proposals` - отклики бухгалтеров
- `orders` - принятые заказы
- `payments` - платежи
- `reviews` - отзывы
- `chats`, `messages` - чаты и сообщения

### Безопасность:
- Row Level Security (RLS) включен для всех таблиц
- Политики доступа настроены для защиты данных
